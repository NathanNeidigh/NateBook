## NetworkManager

NetworkManager is a staple program that provides various networking and connectivity features. Known networks are stored in connection files found in /etc/NetworkManager/system-connections. [Here](https://networkmanager.dev/docs/man-pages/) are some good documentation for using nmcli and creating config files for different networks.
